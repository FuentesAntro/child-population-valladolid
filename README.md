# 🗺️ Child Population Mapping — Province of Valladolid

> Academic cartography project · Auxiliary Techniques in Ethnography  
> **Universidad de Sevilla** · 2026

---

## 📌 What is this project?

Choropleth map showing the percentage of population aged 14 and under 
across all municipalities in the Province of Valladolid, Spain.

Produced as part of the course *Auxiliary Techniques in Ethnography* 
(Social and Cultural Anthropology, Universidad de Sevilla), this map 
applies standard cartographic composition principles using GIS software.

---

## 🛠️ Tools & Data Sources

| Element | Detail |
|---------|--------|
| **Software** | ArcGIS Pro |
| **Projection** | UTM ETRS89 Zone 30N |
| **Data sources** | INE (National Statistics Institute) · DERA (Andalusian Spatial Data) |
| **Classification** | 5-interval choropleth |

---

## 🗺️ Map Components

- Main map: municipalities of Valladolid by child population %
- Inset map 1: European Union highlighting Spain
- Inset map 2: Spain highlighting the province of Valladolid
- Scale bars, north arrow, legend, and spatial reference

---

## 📊 Key Findings

- Municipalities surrounding **Valladolid city** show the highest 
child population rates (>10.8%)
- Rural and peripheral municipalities show significantly lower rates 
(0–3.9%), reflecting depopulation patterns
- Clear urban-rural divide in demographic structure across the province
